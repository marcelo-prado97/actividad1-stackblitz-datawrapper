Este proyecto muestra la visualización de datos utilizando gráficos embebidos desde **Datawrapper**, organizados de manera clara en una página web sencilla.

Incluye gráficos de:
- Emisiones de CO₂ per cápita.
- Variación del CO₂ por país.
- Emisiones totales de CO₂.
- Scatter plot de CO₂.
- Índice de CO₂ Kg/1000$.
